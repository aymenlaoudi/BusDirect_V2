# 🚌 BusDirect

Site de réservation de bus (20 trajets).

🔗 Site en ligne : https://busdirectv2-beta.vercel.app/
🔗 Code : https://github.com/aymenlaoudi/BusDirect_V2

## Fonctionnalités
- Liste des trajets (recherche, filtre, pagination)
- Réserver, modifier et supprimer une place
- Sièges VIP (1 à 4) à +10 %
- Liste d'attente quand le trajet est complet
- Données gardées avec localStorage

## Technologies
HTML, Tailwind CSS, JavaScript

## Lancer le projet
npm install
npm run dev
Ouvrir index.html avec Live Server
