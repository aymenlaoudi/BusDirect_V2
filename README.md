# 🚌 BusDirect

BusDirect est une application web de réservation de places de bus.
Elle permet de consulter 20 trajets, de réserver un siège dans la cabine
du bus, et d'inscrire un passager en liste d'attente quand le trajet est complet.

Projet réalisé en HTML, Tailwind CSS et JavaScript

🔗 Site en ligne : https://busdirectv2-beta.vercel.app/
🔗 Code : https://github.com/aymenlaoudi/BusDirect_V2

## Fonctionnalités
- Liste des trajets (recherche, filtre, pagination)
- Réserver, modifier et supprimer une place
- Sièges VIP (1 à 4) à +10 %
- Liste d'attente quand le trajet est complet
- Données gardées avec localStorage

## Technologies
HTML, Tailwind CSS, JavaScript

## Lancer le projet
npm install
npm run dev
Ouvrir index.html avec Live Server
